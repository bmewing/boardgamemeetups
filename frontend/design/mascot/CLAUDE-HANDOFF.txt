GREG THE GROUPER: ASSETS AND INTEGRATION HANDOFF

All paths below are relative to frontend/. The original eight poses are already integrated in several pages. Preserve those placements when using the additional variants.

REACT ENTRY POINT
  src/components/mascot/Grouper.tsx
  src/components/mascot/Grouper.css
  src/components/mascot/MascotNote.tsx (existing message-layout helper)

From a file directly inside src/pages/:
  import { Grouper } from '../components/mascot/Grouper'

  <Grouper pose="oops" size={112} animated={false} label="" />
  <Grouper pose="winner" size={112} label="" />
  <Grouper pose="shuffle" size={112} label="" />
  <Grouper pose="head" size={40} label="" />

Grouper accepts pose, size, animated, label and className. An empty label marks decorative art. The head pose is always still and uses responsive PNG sizes. Animated web SVGs respect prefers-reduced-motion.

NEW VARIANTS AND INTENDED USE
  oops: Greg with a sheepish expression beside spilled dice. Use beside recoverable errors, with the original error text and retry action still visible. Files: public/mascot/grouper-oops.svg and .png; public/mascot/anim/grouper-oops.gif and .webp.
  winner: Greg proudly holding a gold trophy. Use for a recorded competitive winner or a cooperative win in src/components/PlayLogPanel.tsx. Keep general vote/RSVP success on cheer. Files follow grouper-winner with the same locations and extensions.
  shuffle: Greg with two independently moving card packets. Use for loading and preparing results, with visible loading text or an accessible status. Files follow grouper-shuffle with the same locations and extensions. Idle is for calm decorative moments, not loading.
  head: Tight smiling face for inline notes, avatars and email headers. Use below about 60px instead of full-body art. public/mascot/grouper-head.png is 512px; grouper-head-32.png, -48.png, -64.png, -128.png and -256.png are native smaller sizes. Static grouper-head.svg and grouper-head.webp also exist. There is no animated head GIF or animated head WebP.
  social: public/share.jpg is the new 1200x630 image (compressed JPEG, about 95 KB) with Greg and the Board Game Group name. index.html uses it for Open Graph and a large Twitter/X summary card. Its source is design/mascot/source/social.png.

Page-level use of the new oops, winner, shuffle and head variants remains available for Claude to integrate. This asset update registers all four in Grouper; it does not replace all error boxes or loaders across the app.

FORMAT CHOICES
  SVG: self-contained generated raster art plus web animation; preferred on the website.
  PNG: transparent 512px still, including props.
  Animated WebP: transparent 256px portable animation.
  GIF: cream-background 256px animation, suitable for email or sharing.
  Head portraits: static artwork in PNG/WebP/SVG; native PNG sizes for small placements.
All full-body animations loop over 4.8 seconds. Raw GIF/WebP animations cannot respond to reduced-motion preferences by themselves.

MOTION
The die, meeple and shuffle card packets move independently. The meeple uses eight generated views of an extruded wooden piece, with visible sides and thickness as it turns; its still and reduced-motion pose show a three-quarter view. The source sheet is design/mascot/source/meeple-turntable.png, packaged by meeple-turntable.cjs. Other full-body poses use gentle whole-body floating, rocking, breathing or hopping, with small accents where relevant. The wave fin and card fan remain part of their original still artwork. These are illustrated poses with layered motion, not fully articulated character animation.

The oops dice were corrected to three separate cubes with standard pip layouts and consistent face edges. Existing oops and twirl file paths are unchanged, so current page placements pick up both corrections automatically.

To re-export only these two SVGs after an artwork change:
  node design/mascot/render-poses.cjs oops twirl
